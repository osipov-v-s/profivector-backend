##О проекте 

B2B-направление проекта для оценки профессионального соответствия, подбора и развития сотрудников промышленных предприятий. 

ПрофиВектор развивается как отдельная ветка на базе результатов основного направления проекта ФСИ / НИОКР.

Включает:

- пилотирование на промышленных предприятиях; - диагностику сотрудников;

- математическую модель соответствия;

- backend и web-платформу;

- организационную и коммерческую работу;

- развитие продукта и взаимодействие с предприятиями.
